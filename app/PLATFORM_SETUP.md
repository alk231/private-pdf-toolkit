# Native platform setup notes

The checked-in Flutter source intentionally keeps platform-specific scaffolding generated by Flutter, rather than committing generated build files. From this directory, run `flutter create --platforms=android,ios .` before building.

## Android

- `android/app/src/main/AndroidManifest.xml`: add `INTERNET` and `CAMERA` permissions; set `android:allowBackup="false"` and `android:usesCleartextTraffic="false"` on `<application>`.
- `android/app/build.gradle` or `.kts`: set `minSdk` to 23 or higher.
- Use system certificate validation. Do not add a permissive trust manager or custom bad-certificate callback.
- Generate a release keystore locally and keep it, `key.properties`, and credentials out of Git.

## iOS

- `ios/Runner/Info.plist`: add `NSCameraUsageDescription` and `NSPhotoLibraryUsageDescription` with user-facing explanations.
- Keep App Transport Security enabled. Use a valid certificate chain for the configured HTTPS server.
- Signing and release builds require macOS, Xcode, and your Apple developer team.

The app uses only the packages declared in `pubspec.yaml`; none is an analytics, crash-reporting, advertising, or PDF processing SDK.
